# Sprint 1 — SKIPline

## Sprint Goal
Students can browse the canteen menu and place a food order online before arriving.
## Selected items
- [F] Students need to see the canteen menu and prices before ordering.
- [F] Students need to place and pay for an order before arriving at the canteen.
## Definition of Done
- [ ] A student can view the canteen menu with prices on the ordering page.
- [ ] A student can select items, pay, and receive an order confirmation.
- [ ] The order confirmation shows a pickup time.
- [ ] The feature has been tested by at least one person other than the author.
